# One Line, One Laugh

A single deadpan line about a gym membership so rarely used that each visit
costs more than the taxi taken there — to avoid walking to the place where
you pay to walk.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating the directory if
needed). Python standard library only.
